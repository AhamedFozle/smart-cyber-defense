Interpretation Notes
----------------------------------------------------------------------
This experiment evaluates trigger-shape sensitivity while keeping poisoning rate, target class, trigger footprint, trigger position, model architecture and training duration fixed.

The results should be interpreted as sensitivity evidence for this experimental configuration and should not be generalized as universal behavior for all datasets, models or backdoor attacks.

Because this experiment uses 8 training epochs, its clean-accuracy values should not be directly compared with the standardized 20-epoch baseline of the main experiment.

ASR is evaluated using only non-target-class CIFAR-10 test images. Therefore, the eligible test population is 9000 images.
