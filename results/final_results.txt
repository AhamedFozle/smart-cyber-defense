============================================================
6. METHODOLOGICAL NOTES
============================================================

Activation Clustering was evaluated using a
label-independent cluster-size heuristic. The smaller
K-Means cluster was designated as suspicious without
using ground-truth poison labels. Ground-truth labels
were used only for calculating evaluation metrics.

Spectral Signatures currently assumes a known poisoned
sample count when selecting outliers.

The Neural Cleanse experiment is a localized
Neural Cleanse-style implementation rather than a full
standard Neural Cleanse implementation.

ABS is implemented as an ABS-style neuron stimulation
prototype rather than a complete standard ABS implementation.

STRIP currently uses a threshold selected using labeled
data and therefore should be reported with this limitation.
